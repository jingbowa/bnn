The recurrence evaluates the binomial ratio without constructing large binomial coefficients. The maintained implementation keeps the exact nonzero support, rather than cutting off small weights arbitrarily. One query costs O(nd + n log n).

Squared distances preserve Euclidean ordering. Direct coordinate differences avoid a cancellation problem that can occur when distances are formed by subtracting large squared norms.

One ordering serves both scales

Cache the rank weights for s₁ and s₂, or their combined vector. Use the same distance order for the two base estimates.

wcombinedi = a1wi(n,s1) + a2wi(n,s2),
a1 = −1 / [(s2/s1)2/d−1],   a2 = 1−a1.

The coefficients use the actual integer scales and distance dimension. Rounding a proposed second scale changes the ratio; recompute the coefficients for that ratio. A stable logarithmic/exponential formulation helps when ratios are close.

The base estimator's subsampling scheme and the inference bootstrap are distinct. BNN uses all fixed-size subsets without replacement; the bootstrap resamples the training dataset with replacement and then evaluates BNN on that resample.

The bootstrap sample variance uses denominator B−1. The jackknife is centered on the original estimate as in the paper's formula, and scales must be admissible for the n−1 sample.

Inference scope · Implementation notes.

Scale selection defines the procedure

The package's held-out helper minimizes global validation MSE over supplied pairs. Each validation query's distance ordering is shared across pairs, making the search cheaper than fitting and sorting anew for every candidate.

The paper replication includes its pointwise tuning procedures. Specify which rule is used when reporting results. Bootstrap inference with fixed selected scales does not automatically include the randomness of the selection step.

The metric and workspace are part of computation

Euclidean distance on differently scaled features changes the neighborhood. Choose transformations and scaling intentionally, and apply them consistently. The dimension affects locality and the bias-correction coefficients.

Accelerator prediction works in bounded query batches. The direct-difference distance workspace scales with batch size, n, and d. Reusing fitted weights removes repeated construction but does not remove distance calculation or sorting for a new query.

Exact ordering is retained in the maintained implementation. A future approximate neighbor search would need its own accuracy analysis. Run the current implementation.
